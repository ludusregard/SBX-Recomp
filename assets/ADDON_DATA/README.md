# Addon data

New content loaded beside the base game. Replacements for the game's own
files go in `assets/PATCH_DATA/`.

- `CUSTOM_MUSIC/`: your own music in the place of the game's (see
  `CUSTOM_MUSIC/CUSTOM_MUSIC_README.md`).
- The addon loader for new cars and other content isn't built yet
  (`docs/modding-plan.md`).
